# Папка для баннеров главной страницы (banners/)

В эту папку вы можете сохранять свои графические баннеры для каталога!

### 1. Как сохранять файлы:
Сохраняйте изображения в эту папку: `banners/`
Примеры названий:
- `banners/banner-physics.png`
- `banners/banner-chemistry.png`
- `banners/banner-biology.png`

### 2. Как настроить отображение:
Откройте файл `banners/banners-config.js` и укажите ваши файлы:

```javascript
window.BANNERS_CONFIG = [
  {
    image: 'banners/banner-physics.png',
    direction: 'Физика', // при клике фильтрует по этому направлению
    alt: 'Кабинеты физики'
  },
  {
    image: 'banners/banner-chemistry.png',
    direction: 'Химия',
    alt: 'Кабинеты химии'
  }
];
```

### 3. Рекомендуемые параметры:
- Формат: PNG, JPG или WebP
- Пропорции: 1920 × 500 px (или ~3.8 к 1)
- Система автоматически переключает баннеры каждые 6 секунд, поддерживает стрелки и круглые индикаторы переключения.
