# Папка для баннеров главной страницы (ELXOLDING)

В эту папку вы можете загружать свои рекламные и тематические баннеры для главной страницы каталога.

### Рекомендуемые параметры баннера:
- **Разрешение**: 1920 × 500 px (или пропорции ~ 3.8 : 1)
- **Форматы**: JPG, PNG, WebP
- **Вес файла**: до 400–600 КБ для быстрой загрузки

### Как добавить новый баннер:
1. Сохраните изображение в эту папку `banners/` (например, `banner-physics.jpg`, `banner-chemistry.jpg` и т.д.).
2. Откройте файл `banners/banners-config.js` и добавьте строку с именем файла.
3. Баннеры будут автоматически сменяться в красивом слайдере на главной странице с плавной анимацией и кнопками перелистывания.
