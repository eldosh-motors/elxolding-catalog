Положите в эту папку ваш свежий файл с ценами и товарами:
1. Excel файл (.xlsx или .xls)
2. Или CSV файл (.csv)
3. Или PDF файл с прайс-листом

Файл Excel может содержать колонки:
- Артикул (или Код, ID)
- Наименование (или Название, Товар)
- Цена (или Цена с НДС, Стоимость)
- Ед. изм. (необязательно)

После того как закинули файл в эту папку:
Дважды кликните по файлу "ОБНОВИТЬ_КАТАЛОГ.bat" в основной папке проекта.
Скрипт автоматически найдет соответствия по артикулу или названию и моментально обновит цены в базе каталога!
Затем в GitHub Desktop нажмите Commit -> Push.
